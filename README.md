# FrontDesk Elite AI — Autonomous Customer Experience Suite

FrontDesk Elite AI is a next-generation, agentic customer support and booking assistant built explicitly for small businesses. Powered by the **Gemini 2.5 Intelligence Engine**, this application acts as a fully autonomous digital concierge. 

Unlike standard, rule-based chatbots, this assistant uses an **Observe-Think-Act** reasoning loop via native function calling to interact directly with internal data streams, handle appointments, pitch promotions, and recognize when to step aside for human intervention.

---

## 🌟 Key Features

*   **Premium Interactive UI:** An immersive glassmorphism layout featuring a dark gradient background, styled with Tailwind CSS and FontAwesome iconography.
*   **Agentic Booking Automation:** Instead of outputting plain text, the AI fetches real-time available time slots and converts them into attractive, interactive web reservation cards.
*   **Proactive Store Promotion:** Configured with a system directive to dynamically pitch active store specials (e.g., the *Summer Glow Makeover 20% off deal*) during relevant customer inquiries.
*   **Quick-Action Navigation Sidebar:** Offers customers instant shortcuts to explore the store catalog, check calendar availability, or request direct help.
*   **Human-in-the-Loop Safeguard:** Built-in sentiment analysis and explicit keyword detection flags trigger an immediate backend escalation alert, pausing the AI to transition the thread to a live team member smoothly.
